# 第2周-Section_2：混合检索 + Rerank 重排 — 生产级高频面试题

## Q1: 为什么需要混合检索？纯向量检索有什么问题？

**答**：
纯向量检索的问题：
1. **精确匹配弱**：用户搜"Error 403 Forbidden"，向量检索可能匹配到"HTTP错误处理"（太泛）
2. **专有名词差**：人名、产品名、代码变量名等，向量检索效果不好
3. **短查询语义不足**：查询太短时，Embedding 语义信息少

混合检索 = BM25（关键词精确匹配）+ 向量检索（语义匹配），互补。

---

## Q2: BM25 的原理是什么？

**答**：
BM25 = TF × IDF（带长度归一化）

- **TF（词频）**：词在文档中出现越多 → 越相关
- **IDF（逆文档频率）**：词在整个语料库中越罕见 → 越有区分度
- **长度归一化**：防止长文档因为词频高而总是排前面

**优点**：精确匹配强，不需要 Embedding 模型，速度快
**缺点**：无法理解语义，"猫"和"猫咪"不会匹配

---

## Q3: 混合检索如何融合多路结果？

**答**：
常用方法：**RRF（Reciprocal Rank Fusion）**

```python
score = Σ 1 / (k + rank_i)  # k 通常取 60
#k 是平滑常数，防止排名过高的文档得分过大
```

**为什么用 RRF 而不是加权平均？**
- 不同检索器的分数尺度不同（BM25 分数 vs 余弦相似度），无法直接比较
- RRF 只看排名，不看分数，天然兼容不同检索器
- 对排名靠前的文档给更高权重

---

## Q4: 什么是 Rerank？为什么需要它？

**答**：
**Rerank** 是用 Cross-Encoder 模型对候选文档重新打分排序。

**需要的原因**：
- 检索阶段用 Bi-Encoder（快但粗糙），只编码单个文档
- Rerank 用 Cross-Encoder（慢但精准），将问题和文档拼接后一起编码，能捕捉更细粒度的交互

**两阶段架构**：
1. 召回：BM25 + 向量检索 → 粗筛 Top-20
2. 精排：Cross-Encoder 打分 → 重排序 → 输出 Top-5

---

## Q5: Bi-Encoder 和 Cross-Encoder 的区别？

**答**：
| 维度 | Bi-Encoder | Cross-Encoder |
|------|-----------|---------------|
| 输入 | 问题和文档分别编码 | 问题和文档拼接后一起编码 |
| 速度 | 快（可预计算文档向量） | 慢（每次都要重新计算） |
| 精度 | 粗糙 | 精准 |
| 用途 | 检索阶段（召回） | Rerank 阶段（精排） |

**生产方案**：
- Bi-Encoder：BGE、OpenAI text-embedding-3-small
- Cross-Encoder：bge-reranker、Cohere Rerank

---

## Q6: Rerank 的延迟如何优化？

**答**：
1. **控制候选数量**：Rerank 只处理 Top-20，不是全部文档
2. **用轻量模型**：bge-reranker-base 比 large 快 3 倍
3. **GPU 加速**：Cross-Encoder 在 GPU 上推理快 10 倍
4. **异步并行**：多查询改写场景下，多个子问题可并行执行各自的「检索→Rerank」流程（单个子问题内检索和Rerank仍串行，但子问题之间并行）
5. **缓存**：相同问题+文档的 Rerank 分数缓存

---

## Q7: 完整的 RAG 检索流程是怎样的？

**答**：
```
用户问题
  ↓
Query Transformation（HyDE / 多查询改写）
  ↓
混合检索：BM25 + 向量检索 → RRF 融合
  ↓
Rerank 重排序（Cross-Encoder）
  ↓
Top-K 文档 → 拼接 Prompt → LLM 生成回答
```

每个阶段的作用：
- Query Transformation：优化查询，提高召回
- 混合检索：关键词+语义互补
- Rerank：精排，提高准确率
- LLM：基于检索结果生成回答

---

## Q8: 如何评估混合检索的效果？

**答**：
**评估指标**：
- **Recall@K**：Top-K 中包含相关文档的比例
- **MRR**：第一个相关文档的平均排名倒数
- **NDCG**：排序质量（考虑位置权重）

**评估方法**：
1. 准备标注数据集（问题 + 相关文档）
2. 对比：纯向量 vs 混合 vs 混合+Rerank
3. 通常混合+Rerank > 混合 > 纯向量
