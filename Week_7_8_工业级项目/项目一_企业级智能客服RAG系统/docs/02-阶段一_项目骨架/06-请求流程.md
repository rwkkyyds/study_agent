# 06 - 请求流程

> 阶段一中，一次完整的 HTTP 请求生命周期。

## 整体流程（阶段一）

```
客户端（浏览器/curl）
  │
  ▼
uvicorn 服务器（ASGI）
  │
  ▼
FastAPI 路由匹配
  │
  ├─── GET /health ──→ health_check() ──→ {"status":"ok", ...}
  │
  └─── GET /version ──→ version() ──→ {"app":"...", "version":"..."}
  │
  └─── 其他路径 ──→ 404 Not Found
```

## 详细请求生命周期

```
请求到达 uvicorn
  │
  ├── 1. FastAPI 创建 Request 对象
  ├── 2. 遍历中间件（当前无自定义中间件）
  ├── 3. 路由匹配（URL + HTTP Method）
  ├── 4. 执行路由函数
  │       ├── 读取配置（get_settings()）
  │       └── 返回响应字典
  ├── 5. FastAPI 自动 JSON 序列化
  ├── 6. 返回 Response 对象
  └── 7. uvicorn 发送给客户端
```

## 应用启动流程

```
uvicorn app.main:app --reload
  │
  ├── 1. 导入 app.main
  │       ├── 导入 get_settings() → 读取配置
  │       ├── 导入 init_db() → 数据库会话
  │       └── 创建 FastAPI 实例
  │
  ├── 2. 注册 lifespan 管理器
  ├── 3. 注册路由：
  │       ├── GET /health → health_check
  │       └── GET /version → version
  │
  ├── 4. lifespan 启动：
  │       ├── 记录日志 "application_started"
  │       └── init_db() → 创建 SQLite 数据库表
  │
  └── 5. 监听端口 8000，等待请求
```

## 测试流程

```
pytest tests/test_health.py -v
  │
  ├── 1. 导入 TestClient(app)
  ├── 2. 创建 FastAPI 测试客户端
  ├── 3. 执行 test_health_check():
  │       ├── GET /health → 检查 status_code == 200
  │       └── 检查 body.status == "ok"
  │
  └── 4. 执行 test_version():
          ├── GET /version → 检查 status_code == 200
          └── 检查 body.version == "0.1.0"
```
