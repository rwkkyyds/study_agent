## 运行方式

### 1. 安装依赖（首次）

```powershell
cd 项目一_企业级智能客服RAG系统
.\.venv\Scripts\pip install -r requirements.txt
```

### 2. 配置环境变量

```powershell
cp .env.example .env
```

无需修改默认值即可运行。

### 3. 启动服务

```powershell
.\.venv\Scripts\uvicorn app.main:app --reload --port 8000
```

### 4. 验证

```powershell
# 健康检查
curl http://127.0.0.1:8000/health
# → {"status":"ok","environment":"development"}

# 版本
curl http://127.0.0.1:8000/version
# → {"app":"enterprise-customer-service-rag","version":"0.1.0"}

# OpenAPI 文档
# 浏览器打开 http://127.0.0.1:8000/docs
```

### 5. 运行测试

```powershell
.\.venv\Scripts\pytest tests/test_health.py -v
```

## 依赖管理

### 核心依赖

| 包 | 用途 | 为什么选它 |
|----|------|------------|
| `fastapi` | Web 框架 | 异步性能好、自动 OpenAPI |
| `pydantic-settings` | 配置管理 | 环境变量自动读取 |
| `uvicorn` | ASGI 服务器 | FastAPI 标准启动器 |
| `sqlalchemy` | ORM | 成熟稳定、2.0 新语法 |
| `pytest` | 测试框架 | 生态好、fixture 灵活 |

```

```

## 开发模式优势

1. **零外部依赖**：SQLite 无需安装 Docker，本地即可运行
2. **配置可切换**：改一行 `DATABASE_URL` 即可从 SQLite 切换到 PostgreSQL
3. **测试隔离**：每个测试 fixtrue 重建表，互不干扰
4. **渐进扩展**：每个阶段都是独立可验证的切片，不会一次产生大量不可调试的代码
