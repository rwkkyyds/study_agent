# 01 - 应用入口（main.py）

> 文件路径：`app/main.py`

## 用途

FastAPI 应用入口。负责启动服务、管理生命周期、注册路由。

## 核心组件

### `lifespan(app: FastAPI)` — 应用生命周期管理器

```
启动时 ──→ 记录日志 ──→ init_db() 建表 ──→ 服务运行 ──→ 关闭时记录日志
```

**用途**：替代已弃用的 `@app.on_event("startup")`，在应用启动时初始化数据库，关闭时清理资源。

**关键代码**：
```python
@asynccontextmanager
async def lifespan(app: FastAPI):
    logger.info("application_started ...")
    init_db()                    # 启动时建表
    yield
    logger.info("application_shutdown ...")
```

### `app = FastAPI(...)` — FastAPI 应用实例

**参数**：
- `title`: 服务名称，OpenAPI 文档显示
- `version`: 版本号，从配置读取
- `description`: 服务描述
- `lifespan`: 生命周期管理器

### 路由注册

```python
app.include_router(auth_router)   # 阶段二加入
```

后续阶段会在此添加更多路由：
```python
# app.include_router(chat_router)    # 阶段四加入
# app.include_router(document_router) # 阶段三加入
```

### `GET /health` — 健康检查

**用途**：Kubernetes/负载均衡器探活。

**返回**：
```json
{"status": "ok", "environment": "development"}
```

### `GET /version` — 版本信息

**用途**：部署时确认版本，辅助问题定位。

**返回**：
```json
{"app": "enterprise-customer-service-rag", "version": "0.1.0"}
```
