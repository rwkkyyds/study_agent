# 04 - 接口与测试（health/version + test）

> 接口文件：`app/main.py`
> 测试文件：`tests/test_health.py`

## 接口说明

### `GET /health` — 健康检查

**用途**：Kubernetes/负载均衡器探活，或 Docker HEALTHCHECK。

**请求**：
```
GET /health
```

**响应**（200 OK）：
```json
{
  "status": "ok",
  "environment": "development"
}
```

### `GET /version` — 版本信息

**用途**：确认部署版本，辅助问题定位（"这个版本修了这个 bug 吗？"）。

**请求**：
```
GET /version
```

**响应**（200 OK）：
```json
{
  "app": "enterprise-customer-service-rag",
  "version": "0.1.0"
}
```

## 测试说明

### `test_health.py` — 健康检查测试

**测试内容**：

| 测试函数 | 验证点 | 预期结果 |
|----------|--------|----------|
| `test_health_check()` | `/health` 返回 200 | `status == "ok"` |
| `test_version()` | `/version` 返回 200 | `version == "0.1.0"` |

**测试方式**：使用 `fastapi.testclient.TestClient`，无需启动服务。

```python
from fastapi.testclient import TestClient
from app.main import app

client = TestClient(app)

def test_health_check():
    response = client.get("/health")
    assert response.status_code == 200
    assert response.json()["status"] == "ok"
```

## 运行方式

### 启动服务
```powershell
cd 项目一_企业级智能客服RAG系统
.venv\Scripts\uvicorn app.main:app --reload --port 8000
```

### 测试接口
```powershell

curl http://127.0.0.1:8000/health

# 版本
curl http://127.0.0.1:8000/version
```

### 运行测试
```powershell
.venv\Scripts\pytest tests/test_health.py -v
```
