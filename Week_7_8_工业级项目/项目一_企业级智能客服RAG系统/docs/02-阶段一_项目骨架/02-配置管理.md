# 02 - 配置管理（config.py）

> 文件路径：`app/core/config.py`

## 用途

集中管理所有环境变量，避免把密钥和环境差异写死在业务代码中。

## 核心类

### `class Settings(BaseSettings)`

继承 `pydantic_settings.BaseSettings`，自动从环境变量和 `.env` 文件读取配置。

**配置项**：

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `app_name` | str | `enterprise-customer-service-rag` | 应用名称 |
| `app_version` | str | `0.1.0` | 应用版本号 |
| `environment` | str | `development` | 运行环境：development/production |
| `log_level` | str | `INFO` | 日志级别 |
| `database_url` | str | `sqlite:///./rag_dev.db` | 数据库连接字符串 |
| `db_echo` | bool | `False` | SQLAlchemy 日志输出 |
| `jwt_secret_key` | str | `change-me-in-env` | JWT 签名密钥 |
| `jwt_algorithm` | str | `HS256` | JWT 加密算法 |
| `jwt_expire_minutes` | int | `60` | Token 过期时间 |
| `redis_url` | str | `` | Redis 连接（可选） |
| `milvus_host` | str | `` | Milvus 主机（可选） |
| `milvus_port` | str | `19530` | Milvus 端口 |
| `llm_provider` | str | `mock` | LLM 提供方：mock/openai |
| `llm_api_key` | str | `` | LLM API Key |
| `llm_model` | str | `` | LLM 模型名称 |

### `get_settings() -> Settings`

**用途**：`@lru_cache` 缓存的配置工厂函数，避免每次请求重复读取环境变量。

**用法**：
```python
from app.core.config import get_settings
settings = get_settings()
print(settings.app_version)
```

## 配置加载优先级

```
环境变量 > .env 文件 > 默认值
```

## 环境变量配置

复制 `.env.example` 到 `.env`，按需修改：

```ini
APP_NAME=enterprise-customer-service-rag
APP_VERSION=0.1.0
ENVIRONMENT=development
LOG_LEVEL=INFO
JWT_SECRET_KEY=replace-with-a-long-random-secret
```
