# 03 - 数据库会话（session.py）

> 文件路径：`app/db/session.py`

## 用途

管理 SQLAlchemy 数据库引擎、会话生命周期，提供依赖注入接口。

## 设计原则

- **开发环境**：SQLite（零配置，无需 Docker，auto_vacuum）
- **生产环境**：PostgreSQL（通过 `DATABASE_URL` 环境变量切换）
- **切换方式**：只需改 `.env` 中的 `DATABASE_URL`，代码无需修改

## 核心组件

### 连接字符串

```python
# SQLite 本地开发
DATABASE_URL = "sqlite:///./rag_dev.db"

# PostgreSQL 生产环境
DATABASE_URL = "postgresql://user:pass@host:5432/dbname"
```

### `engine` — 数据库引擎

```python
engine = create_engine(DATABASE_URL, connect_args=connect_args, echo=settings.db_echo)
```

- `connect_args`: SQLite 需要 `check_same_thread=False`（FastAPI 多线程访问）
- `echo=True`: 打印所有 SQL 语句，调试用

### `SessionLocal` — 会话工厂

```python
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
```

- `autocommit=False`: 手动控制事务
- `autoflush=False`: 查询前不自动刷新

### `class Base(DeclarativeBase)` — 声明式基类

所有模型继承此基类：

```python
class User(Base):
    __tablename__ = "users"
    ...
```

### `init_db()` — 初始化建表

```python
def init_db():
    Base.metadata.create_all(bind=engine)
```

**用途**：开发环境自动建表，在 `lifespan` 启动时调用。

### `get_db()` — 依赖注入接口

```python
def get_db():
    db = SessionLocal()
    try:
        yield db           # FastAPI 注入到路由
    finally:
        db.close()         # 请求结束后自动关闭
```

**用法**：
```python
@app.get("/items")
def list_items(db: Session = Depends(get_db)):
    return db.query(Item).all()
```

## 请求生命周期

```
请求进入
  └─→ FastAPI 调用 get_db()
       └─→ 创建 SessionLocal 会话
            └─→ 注入到路由处理函数
                 └─→ 执行查询/修改
                 └─→ 提交/回滚事务
            └─→ 关闭会话
       └─→ 返回响应
```

## 生产环境升级

1. 修改 `.env`：`DATABASE_URL=postgresql://...`
2. 移除 `connect_args`
3. 添加连接池参数：`pool_size=10, max_overflow=20`
4. 使用 Alembic 管理迁移
