# 项目目录结构（阶段一）

```
项目一_企业级智能客服RAG系统/
│
├── app/                                    # 应用核心代码
│   ├── __init__.py                         # 应用包标记
│   ├── main.py                             # FastAPI 入口，lifespan 管理，路由注册
│   │
│   ├── core/                               # 核心基础设施
│   │   ├── __init__.py
│   │   └── config.py                       # Settings 类：集中管理环境变量
│   │
│   └── db/                                 # 数据库层
│       ├── __init__.py
│       └── session.py                      # SQLAlchemy 引擎、会话工厂、Base 基类
│
├── tests/                                   # 测试套件
│   └── test_health.py                       # 健康检查接口测试（阶段一）
│
├── docs/                                    # 项目文档
│   ├── README.md                            # 文档索引
│   ├── 01-项目总览/                          # 项目定位、技术栈、架构
│   └── 02-阶段一_项目骨架/                    # 阶段一文档
│
├── requirements.txt                         # Python 依赖清单
├── .env.example                             # 环境变量配置模板
└── README.md                                # 项目 README
```

## 文件分类说明

### 基础设施层（core/ + db/）
| 文件 | 核心类/函数 | 用途 |
|------|------------|------|
| `config.py` | `class Settings` + `get_settings()` | 管理所有环境变量，缓存单例 |
| `session.py` | `class Base` + `init_db()` + `get_db()` | 数据库引擎、建表、会话注入 |

### 测试层（tests/）
| 文件 | 测试范围 | 数量 |
|------|----------|------|
| `test_health.py` | 健康检查、版本号 | 2 个 |
