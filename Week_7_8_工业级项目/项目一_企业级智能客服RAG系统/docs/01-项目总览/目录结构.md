## 文件分类说明

### 基础设施层（core/ + db/）
| 文件 | 核心类/函数 | 用途 |
|------|------------|------|
| `config.py` | `class Settings` + `get_settings()` | 管理所有环境变量，缓存单例 |
| `session.py` | `class Base` + `init_db()` + `get_db()` | 数据库引擎、建表、会话注入 |

### 数据模型层（models/）
| 文件 | 核心类 | 用途 |
|------|--------|------|
| `user.py` | `class User` | 用户登录、角色权限、密码哈希 |
| `document.py` | `class Document`, `class Chunk` | 文档元数据、切分块、Milvus 关联 |
| `ticket.py` | `class Ticket`, `class Message` | 工单状态流转、消息记录 |

### 业务逻辑层（services/）
| 文件 | 核心函数 | 用途 |
|------|----------|------|
| `auth.py` | `create_user()`, `authenticate_user()`, `create_access_token()`, `get_current_user()`, `require_role()` | 注册、登录、JWT 生成、身份校验、角色权限 |

### API 路由层（api/）
| 文件 | 路由 | 用途 |
|------|------|------|
| `auth.py` | `POST /auth/register` | 注册新用户 |
| | `POST /auth/login` | 登录获取 JWT |
| | `GET /auth/me` | 获取当前用户信息（需登录） |

### RAG 检索层（rag/）
| 文件 | 核心类 | 用途 |
|------|--------|------|
| `embeddings.py` | `class MockEmbedding` | 文本转向量（SHA-256 → 768 维） |
| `vector_store.py` | `class InMemoryVectorStore` | 向量存储 + 余弦相似度搜索 |
| `chunker.py` | `class TextChunker` | 长文本按大小+重叠切分 |
| `retriever.py` | `class Retriever` | 查询 → 嵌入 → 搜索 → 返回 |

### 测试层（tests/）
| 文件 | 测试范围 | 数量 |
|------|----------|------|
| `test_health.py` | 健康检查、版本号 | 2 个 |
| `test_auth.py` | 注册、登录、Token、角色 | 8 个 |
| `test_rag.py` | 嵌入、分块、向量库、检索 | 11 个 |
