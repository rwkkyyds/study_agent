# 实施路线图

## 6 个阶段概览

```
阶段一 ──→ 阶段二 ──→ 阶段三 ──→ 阶段四 ──→ 阶段五 ──→ 阶段六
骨架搭建    认证+数据    入库+检索    客服工作流    稳定性     部署
```

## 阶段一：项目骨架（已完成）

**目标**：建立 FastAPI 应用基础框架，可启动、可测试。

**交付物**：
- ✅ FastAPI 应用入口（lifespan、health、version）
- ✅ 环境变量配置管理（Pydantic Settings）
- ✅ SQLite 数据库会话（SQLAlchemy）
- ✅ 健康检查接口 + pytest 测试

**验证方式**：`pytest tests/test_health.py -v` → 2 passed

## 阶段二：身份认证与数据层（已完成）

**目标**：用户系统、数据模型、JWT 认证。

**交付物**：
- ✅ User 模型（密码哈希、角色、审计字段）
- ✅ Document + Chunk 模型（文档元数据、切分块）
- ✅ Ticket + Message 模型（工单状态流转）
- ✅ JWT 注册/登录/Token 校验
- ✅ 角色权限中间件（admin/agent/customer）

**验证方式**：`pytest tests/test_auth.py -v` → 8 passed

## 阶段三：知识库入库与检索（待开始）

**目标**：Mock Embedding + 向量存储 + 文档分块 + 检索。

**交付物**：
- MockEmbedding（SHA-256 → 768 维向量，无需 API Key）
- InMemoryVectorStore（余弦相似度搜索）
- TextChunker（固定大小 + 重叠切分）
- Retriever（查询 → 嵌入 → 搜索 → 返回）

**验证方式**：`pytest tests/test_rag.py -v` → 11 passed

## 阶段四：客服 LangGraph 工作流（待开始）

**目标**：LangGraph 编排的客服 Agent 工作流。

**交付物**：
- ⏳ IntentClassifier（意图分类）
- ⏳ Agent Tools（知识库搜索、订单查询、转人工）
- ⏳ LangGraph Workflow（StateGraph + 条件路由）
- ⏳ Chat API（`POST /chat`）

**验证方式**：API 测试 + 端到端对话验证

## 阶段五：企业级稳定性（待开始）
