## 二、测试数据库隔离

测试通过 `TEST_DATABASE_URL = "sqlite:///./test_auth.db"` 创建独立 SQLite 数据库，并通过：

```text
app.dependency_overrides[get_db] = override_get_db
```

让认证 API 使用测试会话，而不是生产/开发会话。

每个测试前 `Base.metadata.create_all()`，每个测试后 `Base.metadata.drop_all()`，避免测试之间共享用户数据。

## 四、常见错误排查

### 1. `no such table: users`

原因通常是测试覆盖了 `get_db`，但表没有在测试数据库创建，或测试数据库和应用数据库不一致。检查 `setup_db()` 和 `override_get_db()` 是否使用同一个 `engine`。

### 2. `Subject must be a string`

PyJWT 要求 JWT payload 中的 `sub` 是字符串。检查 `create_access_token()` 是否将用户 id 转换为字符串。

### 3. `/auth/me` 返回 401

依次检查：

1. 请求头是否是 `Authorization: Bearer <token>`。
2. Token 是否复制完整。
3. JWT 密钥和算法是否与签发时一致。
4. Token 是否过期。
5. 用户是否存在且 `is_active=True`。

### 4. 密码验证失败

检查注册时是否调用 `hash_password()`，登录时是否调用 `verify_password()`，不要直接比较明文字符串。
