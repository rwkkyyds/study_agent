# 项目一：企业级智能客服 RAG 系统

## 项目定位

这是第 7-8 周的工业级项目，目标是把前 6 周学习的 RAG、Agent、数据层、性能优化、可观测性和容错能力整合为可运行、可测试、可部署的企业级智能客服后端。

当前优先完成后端。React 前端基础和 SSE 按学习约束暂时跳过，先通过 API 文档和接口测试保证前端可接入。

## 详细文档

请从 [项目文档目录](docs/README.md) 开始阅读。每个阶段完成后必须同时交付代码、测试和对应阶段文档。

- Mock Embedding、文本分块、向量检索内核
- 前 6 周已学习的 LangGraph、Milvus、Redis、容错和可观测性知识
