# AI 面试官系统实施路线图

## 阶段一：项目骨架与最小业务闭环

目标：
- 创建独立项目目录
- 跑通 FastAPI 服务
- 提供健康检查
- 提供题目生成接口
- 提供评分报告接口
- 编写基础测试

验收：
- python -m pytest -q 通过
- /health 返回 ok
- /interviews/questions 能根据简历生成题目
- /interviews/evaluate 能根据回答生成评分报告

## 阶段二：数据层与认证

目标：
- 用户模型
- 面试会话模型
- 问题模型
- 回答模型
- 报告模型
- JWT 认证
- PostgreSQL + Alembic

验收：
- /auth/register、/auth/login、/auth/me 可用
- /interviews/questions 必须带 JWT，生成后保存会话和题目快照
- /interviews/evaluate 必须带 JWT，只能评估当前用户自己的会话
- 回答和评分报告保存到数据库
- Alembic 初始迁移可创建全部阶段二表
- python -m pytest -q 通过

## 阶段三：简历解析

目标：
- 支持 text/markdown/PDF
- 提取项目经历、技能栈、年限、岗位关键词
- 形成候选人画像

验收：
- /resumes/parse 可解析 text/markdown 正文并保存画像
- /resumes/upload 可接收 text/markdown/PDF 文件
- 用户只能读取自己的候选人画像
- /interviews/questions 可通过 resume_profile_id 生成题目
- 面试会话保存使用的 resume_profile_id
- Alembic 阶段三迁移可创建画像表和会话关联字段
- python -m pytest -q 通过

## 阶段四：LangGraph 面试工作流

目标：
- 简历解析节点
- 岗位画像节点
- 题目生成节点
- 候选人回答节点
- 追问节点
- 评分报告节点

验收：
- `app/workflow/interview_graph.py` 提供图式节点工作流
- `/interviews/questions` 返回题目生成节点 trace
- `/interviews/follow-up` 可生成并保存多轮追问
- `/interviews/evaluate` 返回评分报告节点 trace
- 追问记录保存到 `interview_follow_ups`
- 非本人会话不能生成追问
- 阶段四迁移可创建追问表
- `tests/test_interview_graph_workflow.py` 覆盖核心链路

## 阶段五：RAG 与题库

目标：
- 建立岗位知识库
- 支持按岗位技能点检索题目
- 简历项目和题库混合生成问题
- 支持题目难度分层

验收：
- `app/knowledge/question_bank.py` 提供本地结构化岗位题库
- `app/services/question_bank.py` 支持关键词抽取、打分排序和题目转换
- `/question-bank/search` 可按岗位、简历和难度检索题库
- `app/workflow/interview_graph.py` 新增 `rag_retrieval_node`
- `/interviews/questions` 的 workflow_trace 包含 `rag_retrieval_node`
- 面试题结果中混入题库来源题目
- `tests/test_question_bank.py` 覆盖题库 API、retriever 和工作流接入
- python -m pytest -q 通过
