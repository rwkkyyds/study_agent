# 02 - 节点说明

> 核心文件路径：`app/workflow/interview_graph.py`

## 节点总表

| 节点名称 | 方法名 | 所在路径 | 主要职责 |
|----------|--------|----------|----------|
| 简历解析节点 | `_resume_parse_node` | `app/workflow/interview_graph.py` | 从简历文本抽取弱信号，生成会话 ID 和候选人摘要 |
| 岗位画像节点 | `_job_profile_node` | `app/workflow/interview_graph.py` | 根据岗位名称和难度生成岗位关注点 |
| 题目生成节点 | `_question_generation_node` | `app/workflow/interview_graph.py` | 根据简历信号和岗位画像生成结构化面试题 |
| 回答分析节点 | `_answer_analysis_node` | `app/workflow/interview_graph.py` | 从候选人回答中计算技术、结构、项目、风险维度分 |
| 追问节点 | `_follow_up_node` | `app/workflow/interview_graph.py` | 根据回答弱项和原题生成追问 |
| 评分节点 | `_scoring_node` | `app/workflow/interview_graph.py` | 汇总优势、风险和追问 |
| 报告节点 | `_report_node` | `app/workflow/interview_graph.py` | 生成学习建议，形成报告尾部内容 |

## 简历解析节点

文件路径：`app/workflow/interview_graph.py`

方法名：`_resume_parse_node`

输入：

- `state.resume_text`
- `state.job_title`
- `state.difficulty`

输出：

- `state.resume_signals`
- `state.session_id`
- `state.candidate_summary`
- `workflow_trace` 追加 `resume_parse_node`

这个节点不做复杂 NLP，只识别 RAG、Agent、后端、前端、部署等弱信号。阶段三已经有更完整的候选人画像，阶段四这里负责给题目生成链路提供轻量上下文。

## 岗位画像节点

文件路径：`app/workflow/interview_graph.py`

方法名：`_job_profile_node`

输入：

- `state.job_title`
- `state.difficulty`

输出：

- `state.job_profile`
- `workflow_trace` 追加 `job_profile_node`

岗位画像会根据岗位名称识别方向，例如 AI 应用、后端开发、前端或全栈，并形成面试关注关键词。

## 题目生成节点

文件路径：`app/workflow/interview_graph.py`

方法名：`_question_generation_node`

输入：

- `state.resume_signals`
- `state.job_profile`
- `state.question_count`

输出：

- `state.questions`
- `workflow_trace` 追加 `question_generation_node`

阶段四相比前面阶段，新增了 `job_profile` 类型题目，用来体现岗位画像对题目生成的影响。

## 回答分析节点

文件路径：`app/workflow/interview_graph.py`

方法名：`_answer_analysis_node`

输入：

- `state.answer_text`

输出：

- `state.dimension_scores`
- `workflow_trace` 追加 `answer_analysis_node`

它会对回答进行四个维度评分：

- 技术匹配度
- 表达结构
- 项目理解
- 风险意识

## 追问节点

文件路径：`app/workflow/interview_graph.py`

方法名：`_follow_up_node`

输入：

- `state.dimension_scores`
- 可选 `base_question_id`

输出：

- `state.follow_up_questions`
- `workflow_trace` 追加 `follow_up_node`

追问节点会根据薄弱维度生成问题。如果回答缺技术细节，就追技术实现；如果表达结构弱，就要求重新组织；如果风险意识弱，就追监控、降级、回滚。

## 评分节点

文件路径：`app/workflow/interview_graph.py`

方法名：`_scoring_node`

输入：

- `state.dimension_scores`

输出：

- `state.strengths`
- `state.risks`
- `state.follow_up_questions`
- `workflow_trace` 追加 `scoring_node`

评分节点复用追问节点，然后根据分数生成优势和风险。

## 报告节点

文件路径：`app/workflow/interview_graph.py`

方法名：`_report_node`

输入：

- 前面节点已经整理好的优势、风险、追问

输出：

- `state.learning_suggestions`
- `workflow_trace` 追加 `report_node`

报告节点目前生成稳定学习建议。后续可以替换为 LLM 根据岗位、简历、回答动态生成建议。
