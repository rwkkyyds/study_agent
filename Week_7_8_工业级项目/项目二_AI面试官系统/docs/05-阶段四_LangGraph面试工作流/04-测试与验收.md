# 04 - 测试与验收

> 相关路径：`tests/test_interview_graph_workflow.py`

## 测试覆盖

阶段四新增测试文件：`tests/test_interview_graph_workflow.py`

测试覆盖四个方向：

| 测试函数 | 验证点 |
|----------|--------|
| `test_generate_questions_returns_workflow_trace` | 题目生成返回节点 trace，并包含岗位画像题目 |
| `test_follow_up_generates_and_persists` | 追问接口生成问题、保存追问快照、更新会话状态 |
| `test_follow_up_rejects_other_users_session` | 其他用户不能对不属于自己的会话生成追问 |
| `test_evaluate_report_returns_graph_trace` | 评分报告返回回答分析、追问、评分、报告节点 trace |

## 验收命令

## 人工复核重点

如果后续在正常 Python 环境中运行 pytest，重点看：

- `InterviewFollowUp` 表是否随测试数据库创建
- `/interviews/follow-up` 是否返回 200
- 越权追问是否返回 404
- 题目生成 trace 是否为 `resume_parse_node -> job_profile_node -> question_generation_node`
- 报告 trace 是否为 `answer_analysis_node -> follow_up_node -> scoring_node -> report_node`

## 学习重点

- 阶段四测试不只看返回 200，还要看节点 trace 是否符合预期
- 多轮追问必须测试越权路径
- 图式工作流拆节点后，测试可以更清楚地保护每条业务链路
- 迁移和测试都要跟着新增 ORM 模型一起补
