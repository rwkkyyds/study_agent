# 04 - 接口与测试

> 相关路径：`app/api/question_bank.py`、`tests/test_question_bank.py`

## 新增接口

文件路径：`app/api/question_bank.py`

接口：`POST /question-bank/search`

职责：

- 要求 JWT 登录
- 接收题库检索请求
- 调用 `QuestionBankRetriever.search`
- 返回 query keywords 和排序后的题库条目

## 请求模型

文件路径：`app/schemas/question_bank.py`

模型：`QuestionBankSearchRequest`

字段：

- `job_title`
- `resume_text`
- `difficulty`
- `top_k`

## 响应模型

文件路径：`app/schemas/question_bank.py`

模型：`QuestionBankSearchResponse`

字段：

- `query_keywords`
- `items`

每个 item 使用 `QuestionBankItemResponse`，包含题目 ID、技能、难度、题型、题干、期望要点、关键词、来源和检索分数。

## 测试文件

文件路径：`tests/test_question_bank.py`

覆盖内容：

| 测试函数 | 验证点 |
|----------|--------|
| `test_question_bank_search_requires_auth` | 未登录不能访问题库检索接口 |
| `test_question_bank_search_returns_ranked_items` | 登录后能检索题库，且结果按分数排序 |
| `test_question_bank_retriever_converts_items_to_interview_questions` | 检索器能把题库条目转换成面试题 |
| `test_interview_questions_mix_resume_and_question_bank` | 面试题生成 trace 包含 RAG 节点，问题中包含题库来源 |

## 注意事项

`compileall` 和 pytest 会生成 `__pycache__` 编译缓存。当前环境中清理命令被策略拦截，因此未强制删除缓存目录。它们是 Python 编译产物，不影响业务代码和测试结果。

## 学习重点

- 新增服务能力时，要同时补 API 测试和 service 测试
- RAG 接入不是只测接口，还要测它是否真正影响面试题生成
- 题库检索必须受认证保护，因为简历文本可能包含用户隐私
- 没有新增迁移时，也要跑迁移烟测，确认历史迁移没有被破坏
