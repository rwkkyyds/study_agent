# 04 - 测试与验收

> 相关文件：`tests/test_resume_parser.py`

## 测试目标

阶段三测试保护四类能力：

- 解析 text 简历
- 上传 markdown 简历
- 画像用户隔离
- 使用画像生成面试题并保存关联

## 测试重点

| 测试方向 | 验证点 |
|----------|--------|
| text 解析 | 技能、项目、年限、岗位关键词可以被抽取 |
| markdown 上传 | Markdown 符号会被标准化，文件来源会被识别 |
| 用户隔离 | 其他用户无法读取不属于自己的画像 |
| 面试联动 | `resume_profile_id` 能驱动题目生成，并写入面试会话 |

## 迁移验证

阶段三新增了 `resume_profiles` 表，并在面试会话上增加画像关联字段。

迁移验证要确认：

- 空数据库可以从阶段一迁移到阶段三最新结构
- SQLite 本地迁移可通过
- 新表和新外键不会破坏阶段二已有表

## 学习重点

- 新增文件上传接口后，要测试 multipart 请求
- 新增数据归属后，要测试越权访问
- 新增表结构后，要跑 Alembic 迁移烟测
- 功能测试和迁移测试一起通过，才算阶段完成
