# 01 - 解析入口

> 相关文件：`app/api/resumes.py`、`app/services/resume_parser.py`

## 用途

解析入口负责把不同来源的简历统一接入系统。

候选人可能直接粘贴文本，也可能上传 Markdown 或 PDF 文件。接口层需要处理这些输入形式，但后续解析服务应该尽量面对统一的文本内容。

## 两类入口

### 文本解析

文本解析适合用户直接粘贴简历内容。

它支持：

- 普通 text
- markdown 正文
- 可选目标岗位
- 可选来源名称

### 文件上传

文件上传适合更接近真实产品的使用方式。

阶段三支持：

- `.txt`
- `.md` / `.markdown`
- `.pdf`

上传接口会先识别文件类型，再把文件内容转换成可分析文本。

## 为什么先标准化文本

不同格式的简历有不同噪声：

- Markdown 有标题符号、列表符号、链接语法
- PDF 需要抽取页面文本
- 普通文本可能有多余空格和换行

标准化的目的不是美化文本，而是给后续抽取技能、项目、年限提供更稳定的输入。

## 学习重点

- API 层处理输入形式，服务层处理业务解析
- 文件类型判断要基于扩展名和 content type 双重信息
- 不支持的文件类型要明确拒绝
- PDF 解析是工程接入点，后续可以继续增强解析质量
