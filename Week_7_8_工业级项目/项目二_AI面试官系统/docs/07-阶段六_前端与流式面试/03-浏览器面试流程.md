# 03 - 浏览器面试流程

> 关键路径：`frontend/src/App.vue`、`frontend/src/components/DashboardPanel.vue`、`frontend/src/components/SessionsPanel.vue`、`frontend/src/components/InterviewWorkspace.vue`、`app/api/interviews.py`、`app/services/interviews.py`

## 完整流程

阶段六企业级页面从“单次面试 demo”升级为“面试管理后台”。

从用户视角看，流程是：

1. 打开 `/web/`
2. 登录 HR/面试官工作台
3. 查看数据看板，了解历史面试数量、评分和追问情况
4. 进入会话列表，打开历史面试详情
5. 或进入创建面试，输入简历、岗位、难度和题数
6. 生成题目后进入面试工作台
7. 选择题目、保存回答、发起 SSE 追问
8. 提交评分并查看图表化报告
9. 回到列表或看板查看更新后的真实数据

从系统视角看，流程是：

1. `app/main.py` 返回 `app/web/index.html`
2. Vite 构建产物加载 Element Plus 后台应用
3. `App.vue` 从本地存储读取 JWT
4. 登录后调用 `GET /interviews/sessions` 拉取历史会话
5. 数据看板基于历史会话响应计算指标和图表
6. 创建面试调用 `POST /interviews/questions`
7. 打开历史详情调用 `GET /interviews/sessions/{session_id}`
8. 实时追问先调用 `POST /interviews/follow-up/stream-token`
9. 前端用 `EventSource` 调用 `GET /interviews/follow-up/stream`
10. 评分报告调用 `POST /interviews/evaluate`
11. 创建、追问、评分后刷新历史会话列表

## 登录态

文件路径：`frontend/src/components/AuthPanel.vue`

登录继续使用：

- `POST /auth/register`
- `POST /auth/login`

登录成功后，`access_token` 保存在 `localStorage` 的 `ai_interviewer_token`。之后普通 JSON API 都带：

- `Authorization: Bearer <token>`

SSE 流本身仍不带 Authorization，而是使用短期 stream token。

## 数据看板

文件路径：`frontend/src/components/DashboardPanel.vue`

看板只使用 `GET /interviews/sessions` 返回的真实数据，不使用前端假数据。

展示内容包括：

- 总面试数
- 已评分数
- 平均分
- 追问次数
- 会话状态分布图
- 评分趋势图

无数据时使用 Element Plus 空状态，而不是渲染假图表。

## 历史会话

文件路径：`frontend/src/components/SessionsPanel.vue`

历史会话表格展示当前用户自己的会话。点击“查看详情”后，前端调用：

- `GET /interviews/sessions/{session_id}`

详情响应包含题目、已保存回答、追问记录和评分报告。其他用户访问同一个 `session_id` 会返回 404。

## 创建面试

文件路径：`frontend/src/components/InterviewCreatePanel.vue`

创建面试提交字段仍来自 `InterviewQuestionRequest`：

- `resume_text`
- `job_title`
- `difficulty`
- `question_count`

后端生成 `InterviewSession` 和 `InterviewQuestion` 后，前端进入面试工作台，并刷新会话列表。

## 流式追问

文件路径：`frontend/src/components/InterviewWorkspace.vue`

流式追问仍是两步：

1. 用 Bearer JWT 调用 `/interviews/follow-up/stream-token`
2. 用 `EventSource` 打开 `/interviews/follow-up/stream?token=...`

工作台展示四类事件：

- `trace`：工作流节点
- `follow_up`：追问题
- `done`：追问完成
- `error`：异常信息

生成完成后，后端会保存 `InterviewFollowUp`，前端刷新会话列表，让看板和表格同步更新。

## 评分报告

文件路径：`frontend/src/components/ReportPanel.vue`

评分报告来自 `/interviews/evaluate`，页面展示：

- 综合评分
- 等级
- 维度评分柱状图
- 维度评分雷达图
- 优势
- 风险
- 学习建议
- 追问汇总

报告生成后，后端保存 `InterviewAnswer` 和 `InterviewReport`，会话状态更新为 `evaluated`。

## 页面定位

阶段六页面定位为企业级演示后台。它不是最终招聘 ATS，但已经具备真实后台应有的基础能力：认证、真实数据列表、详情页、工作流操作区、加载/空状态、图表和报告复盘。
