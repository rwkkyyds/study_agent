# 04 - 测试与验收

> 关键路径：`tests/test_interview_sessions_api.py`、`tests/test_interview_streaming.py`、`tests/test_web_assets.py`、`frontend/package.json`

## 测试目标

阶段六企业级改造新增了历史 API、Element Plus 后台页面和 ECharts 图表，因此测试覆盖四类风险：

- 当前用户只能读取自己的历史会话
- 会话详情能聚合题目、回答、追问和报告
- Vue 企业后台能成功构建并由 FastAPI 托管
- 原有 SSE 追问、认证、题库、评分链路不回退

本阶段不新增数据库表，因此不新增 Alembic 迁移测试。

## 历史 API 测试

文件路径：`tests/test_interview_sessions_api.py`

覆盖场景：

- 未登录访问 `GET /interviews/sessions` 返回 401
- 当前用户只能看到自己的会话列表
- 无报告会话的 `overall_score` 和 `level` 为 `null`
- 会话详情返回题目、回答、追问和报告
- 其他用户访问同一 `session_id` 返回 404

这些测试证明企业后台列表不是前端假数据，而是来自真实落库记录。

## 静态资源测试

文件路径：`tests/test_web_assets.py`

Vite 构建产物带 hash 文件名，因此测试从 `/web/` 的 HTML 中解析真实 asset 路径，再请求 JS/CSS。

覆盖点：

- `/web/` 返回 200
- 页面包含 `AI 面试官系统`
- 页面包含 Vue 根节点 `id="app"`
- HTML 引用的 `/web/assets/*.js` 可访问
- HTML 引用的 `/web/assets/*.css` 可访问
- JS 内容包含 `EventSource`
- JS 内容包含 `面试管理工作台`
- CSS 内容包含 `.enterprise-shell`

## 流式追问测试

文件路径：`tests/test_interview_streaming.py`

继续覆盖：

- 未登录不能创建 stream token
- 当前用户只能给自己的会话创建 stream token
- 非本人会话返回 404
- 合法 stream token 返回 `text/event-stream`
- SSE 包含 `trace`、`follow_up`、`done`
- 追问完成后写入 `InterviewFollowUp`
- 会话状态更新为 `follow_up_generated`
- 非法、过期、用途不匹配 token 返回 401

## 前端构建验收

在项目二目录执行：

    cd frontend
    npm install
    npm run build
    cd ..

构建成功后应生成：

- `app/web/index.html`
- `app/web/assets/*.js`
- `app/web/assets/*.css`

如果构建提示 chunk 较大，这是 Element Plus 和 ECharts 带来的体积警告，不影响阶段六验收。

## 全量验收命令

    cd frontend
    npm install
    npm run build
    cd ..
    python -m pytest -q

验收标准：

- 前端依赖安装成功
- Vue 企业后台构建成功
- 历史 API 测试通过
- 静态资源测试通过
- SSE 回归测试通过
- 阶段二到阶段五已有认证、简历、题库、追问、评分测试不回退
- 全部 pytest 通过

## 手工验收建议

启动服务：

    uvicorn app.main:app --reload --port 8100

浏览器访问：

- `http://localhost:8100/web/`
- `http://localhost:8100/docs`
- `http://localhost:8100/health`

推荐流程：

1. 登录工作台
2. 查看数据看板
3. 创建一场新面试
4. 在工作台选择题目并保存回答
5. 点击 SSE 追问，观察事件流
6. 生成评分报告，查看图表和报告明细
7. 回到会话列表，确认分数、状态和追问数更新
