# 02 - 企业级前端页面结构

> 关键路径：`frontend/src/App.vue`、`frontend/src/components/*.vue`、`frontend/src/style.css`、`frontend/src/chartSetup.js`、`app/web/`、`app/main.py`

## 为什么重做页面

原先 Vue 页面已经能跑通登录、题目生成、SSE 追问和评分报告，但它更像教学 demo：单页双栏、控件简单、缺少历史数据入口和后台信息架构。

本次改造把页面定位为 HR/面试官后台，核心变化是：

- 用侧边栏和顶部栏建立后台产品结构
- 用数据看板呈现真实会话运营数据
- 用表格承载历史会话，而不是只操作当前会话
- 用 Element Plus 提供专业表单、表格、加载态、空状态和标签
- 用 ECharts 展示状态分布、评分趋势和评分维度
- 不使用前端假数据，全部来自后端真实接口

## 后端数据边界

文件路径：`app/api/interviews.py`

企业后台需要真实历史数据，因此新增两个只读接口：

- `GET /interviews/sessions`
- `GET /interviews/sessions/{session_id}`

它们都需要 Bearer JWT，并且只返回当前用户自己的数据。前端不会放样例候选人列表，也不会展示其他用户会话。

文件路径：`app/services/interviews.py`

service 层基于现有表聚合：

- `InterviewSession`
- `InterviewQuestion`
- `InterviewAnswer`
- `InterviewFollowUp`
- `InterviewReport`

因此本次企业级改造不需要新增数据库表，也不需要新增 Alembic 迁移。

## AppShell 职责

文件路径：`frontend/src/App.vue`

`App.vue` 现在是后台框架层，负责：

- 左侧导航：数据看板、面试会话、创建面试、面试工作台
- 顶部栏：登录状态、刷新按钮、退出登录
- 登录后拉取历史会话列表
- 打开某次历史面试详情
- 保存当前面试题、回答草稿、SSE 事件和报告状态
- 在创建、追问、评分后刷新列表数据

它仍然不引入 Pinia。当前阶段状态量可控，用一个顶层组件协调更利于学习。

## 组件职责

`DashboardPanel.vue` 展示真实聚合指标：总面试数、已评分数、平均分、追问次数，并用 ECharts 展示状态分布和评分趋势。

`InterviewCreatePanel.vue` 负责新建面试。它使用 Element Plus 表单承载岗位、难度、题数和简历文本，调用 `/interviews/questions` 后进入工作台。

`SessionsPanel.vue` 展示历史会话表格。表格字段包括岗位、候选人摘要、状态、难度、题目/回答/追问数量、评分和创建时间。

`InterviewWorkspace.vue` 是核心工作区。它包含题目队列、回答输入、期望要点、SSE 追问事件流和评分按钮。

`ReportPanel.vue` 展示评分报告。它用图表呈现维度评分，并用标签和卡片展示优势、风险、学习建议和追问汇总。

## 构建产物

文件路径：`frontend/vite.config.js`

生产构建仍输出到 `app/web`：

- `app/web/index.html`
- `app/web/assets/*.js`
- `app/web/assets/*.css`

`app/main.py` 继续挂载 `/web`，所以访问入口不变：`http://localhost:8100/web/`。
