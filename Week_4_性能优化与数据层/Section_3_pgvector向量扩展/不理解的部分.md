## 已知注意事项（预记录）

### 1. PostgreSQL 中文全文检索
- `tsvector` + `plainto_tsquery('simple', ...)` 对中文无效
- 需要 `zhparser` 扩展或 jieba 分词才能正确支持中文全文检索
- demo3 中全文检索返回空是该限制导致的正常现象

### 2. BGE 模型维度
- `BAAI/bge-small-zh-v1.5` 输出 **512 维**（不是 384）
- 建表时 `Vector(N)` 的 N 必须与模型输出维度一致

### 3. Windows pgvector 安装
- 本地 PostgreSQL 需要编译安装 pgvector
- 推荐用 Docker：`docker run -p 5433:5432 -e POSTGRES_PASSWORD=123456 pgvector/pgvector:pg17`
