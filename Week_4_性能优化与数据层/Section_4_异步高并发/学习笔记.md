# 异步高并发 — 学习笔记

## 一、协程的本质

### 1.1 async/await 是什么

```python
async def func():   # 定义协程函数
    await xxx        # 让出控制权，事件循环去执行其他协程
```

- `async def`：定义一个**协程函数**，调用它不执行，只返回一个 coroutine 对象
- `await`：**让出控制权**——告诉事件循环"我要等 IO 了，你先去干别的"
- **不是多线程！** 始终在单线程内协作式切换

### 1.2 asyncio.sleep vs time.sleep

| 函数 | 行为 | 事件循环 |
|------|------|----------|
| `await asyncio.sleep(1)` | 非阻塞等待 | 切走执行其他协程 |
| `time.sleep(1)` | **阻塞整个线程** | 事件循环被卡死 |

> ⚠️ **async def 里千万别调 time.sleep()！** 会卡死整个事件循环，所有请求排队。

## 二、并发编排

### 2.1 三种核心模式

| 方法 | 行为 | 适用场景 |
|------|------|----------|
| `asyncio.gather()` | 同时发起，等全部完成 | 并发调用多个 API |
| `asyncio.create_task()` | 后台运行，不阻塞当前 | fire-and-forget 任务 |
| `asyncio.wait_for()` | 带超时的 await | 防止慢服务拖死请求 |

### 2.2 加速比

```
串行：Task-A(1s) → Task-B(1s) → Task-C(1s) = 3s
并发：Task-A(1s) ┐
      Task-B(1s) ├─ 同时发起 = 1s（最慢的那个）
      Task-C(1s) ┘
加速比 = 3x
```

## 三、FastAPI 异步端点

### 3.1 async def vs def

```python
@app.get("/async")     # 事件循环直接调度 → IO 密集首选
async def async_route():
    await asyncio.sleep(1)  # 不阻塞其他请求
    return {"ok": True}

@app.get("/sync")      # FastAPI 在线程池中执行 → 不会阻塞事件循环
def sync_route():
    time.sleep(1)      # 阻塞的是线程池线程，不影响事件循环
    return {"ok": True}
```

**建议：** IO 密集用 `async def`，CPU 密集用 `def` 或 `run_in_executor()`

### 3.2 run_in_executor — CPU 密集任务

```python
@app.get("/cpu")
async def cpu_task():
    def heavy(): ...  # CPU 密集的同步函数
    loop = asyncio.get_running_loop()
    result = await loop.run_in_executor(None, heavy)  # 丢到线程池
    return result
```

### 3.3 BackgroundTasks — 不阻塞响应

```python
@app.post("/send")
async def send(background_tasks: BackgroundTasks):
    background_tasks.add_task(send_email, "user@x.com")
    return {"msg": "邮件后台发送中"}  # 立刻返回，不等待邮件发送
```

## 四、异步数据库

### 4.1 Async SQLAlchemy

```python
from sqlalchemy.ext.asyncio import create_async_engine, async_sessionmaker

engine = create_async_engine("sqlite+aiosqlite:///db.sqlite")
SessionLocal = async_sessionmaker(engine)

async with SessionLocal() as session:
    result = await session.execute(select(User))
    users = result.scalars().all()
```

### 4.2 并发 DB 查询

```python
# 串行：10 次查询 ≈ 1s
for pid in ids:
    user = await query_user(pid)

# 并发：10 次查询 ≈ 0.1s（加速 7.8x）
users = await asyncio.gather(*(query_user(pid) for pid in ids))
```

## 五、协程 vs 线程 vs 进程

| 维度 | 协程 | 线程 | 进程 |
|------|------|------|------|
| 切换代价 | ~100ns | ~1-10μs | ~ms |
| 内存 | ~KB | ~8MB | ~100MB |
| 切换者 | 用户态（await） | OS 抢占 | OS 抢占 |
| 并发模型 | 单线程协作式 | 多线程抢占式 | 多进程 |
| 10000 个 | ~几 MB | ~80GB | ~1TB |
| 适用 | IO 密集型 | 轻量 CPU | 重量 CPU/隔离 |
