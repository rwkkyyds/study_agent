## Q1: MultiServerMCPClient 中的 "calculator" 是否可以随意命名？

### 疑问
在 `demo2_mcp_langgraph.py` 中看到：
```python
mcp_client = MultiServerMCPClient(
    connections={
        "calculator": { 
            "transport": "stdio",
            "command": sys.executable,
            "args": [MCP_SERVER_PATH],
        }
    }
)
```
这里的 `"calculator"` 是固定的名称吗？还是可以随意命名？

### 解答
**可以随意命名**。`"calculator"` 是 `connections` 字典的**键**，作用如下：

1. **标识符作用**：在有多个 MCP Server 时，用来区分不同的 Server
2. **无实际约束**：名称不会影响功能，MCP 工具正常发现和调用

### 示例
```python
# 方案1：多个 Server，使用不同的键名
mcp_client = MultiServerMCPClient(
    connections={
        "math_server": {  # 可以叫任何名称
            "transport": "stdio",
            "command": sys.executable,
            "args": [CALCULATOR_SERVER_PATH],
        },
        "weather_api": {  # 第二个 Server，用不同名称区分
            "transport": "stdio",
            "command": sys.executable,
            "args": [WEATHER_SERVER_PATH],
        }
    }
)

# 获取所有 Server 的工具（合并返回，无需指定来源）
mcp_tools = await mcp_client.get_tools()
```

### 关键点
| 配置项 | 能否修改 | 说明 |
|------|--------|------|
| 字典键（如 `"calculator"`） | ✅ 可随意 | 只需在 `connections` 中唯一 |
| `transport: "stdio"` | ❌ 固定 | MCP 通信协议 |
| `command: sys.executable` | ✅ 可改 | Python 解释器路径 |
| `args: [path]` | ✅ 可改 | MCP Server 脚本路径 |
