# Section 3: MCP 协议实战 - 学习笔记

## 1. MCP 是什么

MCP（Model Context Protocol）是 Anthropic 推出的开放协议，定义了 **LLM ↔ 工具/数据源** 之间的标准通信方式。

```
类比：
  USB-C 统一了充电/数据/视频接口
  MCP 统一了 LLM ↔ 工具的通信接口

传统方式：每个框架一套工具接口，换框架要重写
MCP 方式：工具作为独立服务运行，写一次，任何框架都能用
```

## 2. MCP 架构

```
┌─────────────┐     MCP 协议      ┌─────────────┐
│  MCP Client  │ ←─── stdio ────→ │  MCP Server  │
│  (你的代码)   │     JSON-RPC     │  (工具服务)   │
└──────┬──────┘                   └──────┬──────┘
       │                                 │
       ▼                                 ▼
  LangGraph Agent                  具体工具实现
  (决定调用什么工具)                 (文件读写/API调用等)
```

- **MCP Server**：暴露工具的服务进程
- **MCP Client**：连接 Server、发现工具、调用工具
- **传输方式**：stdio（最常用）、SSE、WebSocket

## 3. MCP Server 创建（MCP 1.x API）

```python
from mcp import types
from mcp.server import Server

server = Server("my-server")

# 注册工具列表
@server.list_tools()
async def handle_list_tools() -> list[types.Tool]:
    return [
        types.Tool(
            name="calculator",
            description="计算数学表达式",
            inputSchema={
                "type": "object",
                "properties": {
                    "expression": {"type": "string"}
                },
                "required": ["expression"]
            }
        )
    ]

# 注册工具调用处理器
@server.call_tool()
async def handle_call_tool(name: str, arguments: dict) -> list[types.TextContent]:
    if name == "calculator":
        result = eval(arguments["expression"])
        return [types.TextContent(type="text", text=str(result))]
```

## 4. MCP Client 使用

```python
from langchain_mcp_adapters.client import MultiServerMCPClient

# 连接 MCP Server
mcp_client = MultiServerMCPClient(
    connections={
        "my-server": {
            "transport": "stdio",
            "command": "python",
            "args": ["server.py"],
        }
    }
)

# 发现工具（返回 LangChain 兼容的工具列表）
tools = await mcp_client.get_tools()

# 工具可直接绑定到 LLM
llm_with_tools = llm.bind_tools(tools)
```

## 5. MCP + LangGraph 集成

```
Agent Node → LLM 决策调用 MCP 工具
    ↓
Conditional Edge → 有 tool_calls
    ↓
ToolNode → 执行 MCP 工具（通过 MCP Client → MCP Server）
    ↓
结果追加到 messages → 回到 Agent Node
```

关键点：
- MCP 工具是异步的，必须用 `ainvoke` 而非 `invoke`
- `ToolNode` 自动处理 MCP 工具的调用
- 工具实现与 Agent 代码完全解耦

## 6. MCP 通信协议（JSON-RPC 2.0）

```json
// Client → Server: 列出工具
{"jsonrpc": "2.0", "id": 1, "method": "tools/list"}

// Client → Server: 调用工具
{"jsonrpc": "2.0", "id": 2, "method": "tools/call",
 "params": {"name": "calculator", "arguments": {"expression": "3+5"}}}

// Server → Client: 返回结果
{"jsonrpc": "2.0", "id": 2,
 "result": {"content": [{"type": "text", "text": "8"}]}}
```

## 7. 三大 MCP Server

| Server | 用途 | 典型工具 |
|--------|------|----------|
| Filesystem | 文件操作 | read_file, write_file, list_directory |
| GitHub | GitHub API | create_issue, search_repos, get_file |
| Playwright | 浏览器 | navigate, click, screenshot |

这些 Server 可以直接使用，不需要自己写：
```bash
npx @modelcontextprotocol/server-filesystem /path/to/dir
npx @modelcontextprotocol/server-github
npx @modelcontextprotocol/server-playwright
```
