# Section 4: PostgreSQL 基础 - 学习笔记

## 1. SQLAlchemy 三层架构

```
Engine（引擎）    → 连接池，管理数据库连接
Session（会话）   → 工作区，跟踪所有变更，commit 提交 / rollback 回滚
Model（模型）     → Python 类，对应数据库表
```

## 2. Model 定义

```python
class User(Base):
    __tablename__ = "users"

    id: Mapped[int] = mapped_column(Integer, primary_key=True)
    name: Mapped[str] = mapped_column(String(50), nullable=False, unique=True)
    email: Mapped[str] = mapped_column(String(100), nullable=False, unique=True)
    created_at: Mapped[datetime] = mapped_column(DateTime, default=datetime.now)

    __table_args__ = (
        Index("idx_user_email", "email"),
    )
```

关键字段类型：`Integer`, `String(n)`, `Boolean`, `DateTime`, `Text`, `Float`

## 3. CRUD 操作

```python
with Session(engine) as session:
    # Create
    user = User(name="张三", email="zhangsan@test.com")
    session.add(user)
    session.commit()

    # Read
    user = session.query(User).filter(User.name == "张三").first()
    all_users = session.query(User).all()

    # Update
    user.email = "new@test.com"
    session.commit()

    # Delete
    session.delete(user)
    session.commit()
```

## 4. 事务

```python
with Session(engine) as session:
    try:
        session.add(user1)
        session.add(user2)
        session.commit()      # 两条都写入
    except:
        session.rollback()    # 两条都撤销
```

- `with Session` 自动管理事务生命周期
- `commit()` = BEGIN → 操作 → COMMIT
- `rollback()` = BEGIN → 操作 → ROLLBACK（全部撤销）

## 5. Pydantic Schema vs SQLAlchemy Model

```
SQLAlchemy Model = 数据库层（表结构、字段类型、索引）
Pydantic Schema  = API 层（请求验证、响应格式）

两者的字段可以不同：
- 请求 Schema：不含 id、created_at（由数据库生成）
- 响应 Schema：不含 password_hash（不暴露给前端）
- Model：包含所有字段
```

```python
class UserCreate(BaseModel):      # 请求
    name: str
    email: str
    password: str

class UserResponse(BaseModel):    # 响应
    id: int
    name: str
    email: str
    class Config:
        from_attributes = True    # 支持从 SQLAlchemy 对象创建
```

## 6. FastAPI 依赖注入

```python
def get_db():
    db = Session(engine)
    try:
        yield db
    finally:
        db.close()

@app.post("/register")
def register(data: UserCreate, db: Session = Depends(get_db)):
    # db 自动创建，请求结束自动关闭
    ...
```

- `Depends(get_db)` = 每次请求自动创建 Session
- `yield` = 请求处理期间持有 Session
- `finally` = 请求结束后自动关闭 Session

## 7. PostgreSQL vs SQLite

| 维度 | SQLite | PostgreSQL |
|------|--------|------------|
| 配置 | 零配置，单文件 | 需安装，需创建数据库 |
| 并发 | 单写多读 | 完全并发 |
| 功能 | 基础 SQL | JSON、全文搜索、pgvector |
| 适用 | 开发/测试 | 生产环境 |
| 连接字符串 | `sqlite:///db.db` | `postgresql+psycopg2://user:pass@host:5432/db` |

**切换只需改一行连接字符串，代码不用改。**

## 8. Alembic 迁移命令

```bash
# 初始化迁移目录
alembic init alembic

# 自动生成迁移脚本（对比 Model 和数据库差异）
alembic revision --autogenerate -m "add users table"

# 执行迁移
alembic upgrade head

# 回滚一步
alembic downgrade -1
```
