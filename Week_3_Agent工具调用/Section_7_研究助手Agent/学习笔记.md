# Section 7 学习笔记：RAG + 联网搜索研究助手 Agent

## 一、研究助手架构（LangGraph StateGraph）

```
用户提问
  │
  ▼
START → agent_node（LLM.bind_tools 决策）
  │
  ├─ 有 tool_calls → ToolNode 执行工具 → 回到 agent_node（循环）
  └─ 无 tool_calls → END（结束）
```

## 二、核心组件（全部来自 Section 2 的 LangGraph 模式）

### 2.1 State 定义

```python
class AgentState(TypedDict):
    messages: Annotated[list[BaseMessage], operator.add]
```

`operator.add` 表示追加而非覆盖，每个节点返回的新消息追加到历史中。

### 2.2 Agent Node

```python
def agent_node(state: AgentState) -> dict:
    llm = ChatOpenAI(api_key=KEY, base_url=URL, model="glm-4-flash", temperature=0)
    response = llm.bind_tools(TOOLS).invoke(state["messages"])
    return {"messages": [response]}
```

关键：`llm.bind_tools(TOOLS)` 让 LLM 知道有哪些工具可用，LLM 自主决定调用哪个。

### 2.3 Conditional Edge

```python
def should_continue(state: AgentState) -> str:
    last = state["messages"][-1]
    return "tools" if isinstance(last, AIMessage) and last.tool_calls else "end"
```

### 2.4 ToolNode

```python
from langgraph.prebuilt import ToolNode
graph.add_node("tools", ToolNode(TOOLS))
```

ToolNode 自动执行 tool_calls 中的工具，结果追加到 messages。

### 2.5 图组装

```python
graph = StateGraph(AgentState)
graph.add_node("agent", agent_node)
graph.add_node("tools", ToolNode(TOOLS))
graph.add_edge(START, "agent")
graph.add_conditional_edges("agent", should_continue, {"tools": "tools", "end": END})
graph.add_edge("tools", "agent")  # 工具执行完回到 agent
```
