# Section 5: Agent Memory 记忆机制 - 学习笔记

## 1. Agent 三种记忆类型

```
短期记忆（Short-term）  → 当前会话的消息历史
  存储：State.messages
  特点：自动累积，会话结束丢失

工作记忆（Working）     → 当前任务的中间状态
  存储：State 的自定义字段（user_name、task_count 等）
  特点：支持 Checkpoint 持久化

长期记忆（Long-term）   → 跨会话的知识和偏好
  存储：Redis / 数据库
  特点：手动管理，可跨会话恢复
```

## 2. LangGraph Checkpoint 机制

```python
from langgraph.checkpoint.memory import MemorySaver

memory = MemorySaver()
agent = graph.compile(checkpointer=memory)

# 通过 thread_id 隔离不同会话
config = {"configurable": {"thread_id": "user-001"}}
result = agent.invoke({"messages": [...]}, config=config)
```

- `checkpointer=memory`：编译时绑定存储后端
- `thread_id`：标识一个会话线程，类似 session_id
- 自动保存每次运行的 State
- 下次 invoke 同一 thread_id 时，自动恢复 State

## 3. MemorySaver vs RedisCheckpointer

| 维度 | MemorySaver | RedisCheckpointer |
|------|------------|-------------------|
| 存储位置 | 内存 | Redis |
| 持久化 | 进程结束丢失 | 持久化 |
| 适用场景 | 开发/测试 | 生产环境 |
| 性能 | 最快 | 快（内存数据库） |
| 多进程共享 | 不支持 | 支持 |

## 4. Redis 在 Agent 中的应用

```python
# 消息历史（LIST）
redis.rpush("agent:messages:user-001", json.dumps(message))
redis.lrange("agent:messages:user-001", -20, -1)  # 最近20条

# 用户画像（STRING）
redis.set("agent:profile:user-001", json.dumps(profile))
redis.get("agent:profile:user-001")

# 过期管理
redis.expire("agent:messages:user-001", 3600)  # 1小时过期
```

Redis 数据结构用途：
- **STRING** → 简单键值（会话数据、缓存）
- **LIST** → 消息历史（RPUSH + LRANGE）
- **HASH** → 用户画像（HSET + HGETALL）
- **SET** → 标签管理
- **ZSET** → 优先级队列

## 5. 会话隔离

```
thread_id = "user-001" → 用户 A 的独立会话
thread_id = "user-002" → 用户 B 的独立会话

两个用户的 State 完全隔离，互不影响。
同一个用户的多轮对话共享 State。
```

## 6. 生产环境建议

1. **开发阶段**：MemorySaver（零配置）
2. **单机生产**：RedisCheckpointer（持久化 + 高性能）
3. **分布式生产**：PostgreSQLCheckpointer（多进程共享）
4. **会话过期**：Redis TTL 自动清理过期会话
5. **消息截断**：messages 超过阈值时截断或摘要压缩
