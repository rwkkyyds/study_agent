# Section 5: Agent Memory 记忆机制 - 生产级高频面试题

## 基础题

### Q1: Agent 的三种记忆类型是什么？

**答：**

| 类型 | 存储位置 | 生命周期 | 示例 |
|------|---------|---------|------|
| 短期记忆 | State.messages | 当前会话 | 对话历史 |
| 工作记忆 | State 自定义字段 | 当前任务（可 Checkpoint） | user_name、task_count |
| 长期记忆 | Redis/数据库 | 永久（手动管理） | 用户画像、历史总结 |

---

### Q2: LangGraph 的 Checkpoint 机制是什么？

**答：**

Checkpoint 是 LangGraph 的 State 持久化机制。编译图时传入 `checkpointer`，每次运行自动保存 State，下次可通过 `thread_id` 恢复。

```python
memory = MemorySaver()  # 或 RedisCheckpointer
agent = graph.compile(checkpointer=memory)
config = {"configurable": {"thread_id": "user-001"}}

# 第一次运行：保存 State
agent.invoke({"messages": [...]}, config=config)

# 第二次运行：自动恢复之前的 State
agent.invoke({"messages": [...]}, config=config)
```

---

### Q3: thread_id 的作用是什么？

**答：**

`thread_id` 标识一个会话线程，类似 Web 应用中的 `session_id`。

- 同一 `thread_id` 的多次 invoke 共享 State（多轮对话）
- 不同 `thread_id` 的 State 完全隔离（多用户）
- 存储在 `{"configurable": {"thread_id": "xxx"}}` 中

## 进阶题

### Q4: MemorySaver 和 RedisCheckpointer 怎么选？

**答：**

| 场景 | 选择 | 原因 |
|------|------|------|
| 本地开发 | MemorySaver | 零配置，进程内 |
| 单机生产 | RedisCheckpointer | 持久化，高性能 |
| 分布式生产 | PostgreSQLCheckpointer | 多进程共享，事务安全 |

切换只需改一行：
```python
# 开发
from langgraph.checkpoint.memory import MemorySaver
memory = MemorySaver()

# 生产
from langgraph.checkpoint.redis import RedisSaver
memory = RedisSaver(redis_url="redis://localhost:6379")
```

### Q5: 会话历史太长怎么办？

**答：**

messages 列表无限增长会撑爆 Token 限制。解决方案：

1. **截断**：只保留最近 N 条消息
   ```python
   messages = state["messages"][-20:]  # 只保留最近20条
   ```

2. **摘要压缩**：让 LLM 总结历史，替换为摘要
   ```python
   if len(messages) > 50:
       summary = llm.invoke("总结以下对话：" + str(messages[-50:]))
       messages = [summary] + messages[-5:]
   ```

3. **滑动窗口**：保留最近 N 轮 + 第一轮（上下文）

### Q6: 怎么实现跨会话的用户画像？

**答：**

```python
# 会话结束时，总结用户信息存入 Redis
profile = {
    "name": "张三",
    "interests": ["Python", "AI"],
    "last_topic": "Agent Memory",
}
redis.set("profile:user-001", json.dumps(profile))
redis.expire("profile:user-001", 86400 * 7)  # 7天过期

# 新会话开始时，加载用户画像
profile = json.loads(redis.get("profile:user-001") or "{}")
# 将画像注入 System Prompt
system_prompt = f"用户姓名：{profile.get('name', '未知')}，兴趣：{profile.get('interests', [])}"
```

## 生产级场景题

### Q7: 多 Agent 协作时怎么共享记忆？

**答：**

1. **共享 State**：多个 Agent 共用同一个 State（LangGraph 的 Multi-Agent 模式）
2. **共享 Redis**：每个 Agent 独立 State，通过 Redis 交换信息
3. **消息总线**：Agent 之间通过消息队列通信

推荐方案：LangGraph 的 `Send` API + 共享 Checkpointer，多个 Agent 节点读写同一个 State。

### Q8: Redis 会话存储的 Key 怎么设计？

**答：**

```
agent:messages:{user_id}      → LIST，消息历史
agent:profile:{user_id}       → STRING/JSON，用户画像
agent:session:{session_id}    → HASH，会话元数据
agent:cache:{hash}            → STRING，LLM 响应缓存
```

命名规范：`{业务}:{数据类型}:{标识符}`，方便管理和批量操作。
