# Section 6: Docker 打包部署 + 第1周 Demo 复盘 学习笔记

## Docker 基础

### Dockerfile 解析
```dockerfile
FROM python:3.12-slim          # 基础镜像：Python 3.12 轻量版
WORKDIR /app                    # 工作目录
COPY requirements.txt .         # 先复制依赖文件（利用缓存层）
RUN pip install -r requirements.txt  # 安装依赖
COPY app.py .                   # 再复制代码（代码改了不用重装依赖）
EXPOSE 8000                     # 声明端口
CMD ["uvicorn", "app:app", "--host", "0.0.0.0", "--port", "8000"]  # 启动命令
```

### 构建与运行
```bash
docker build -t naive-rag .     # 构建镜像，-t 起名
docker run -p 8000:8000 naive-rag  # 运行容器，-p 映射端口
docker run -d -p 8000:8000 naive-rag  # -d 后台运行
docker ps                       # 查看运行中的容器
docker stop <container_id>      # 停止容器
```

### Docker 缓存优化
Dockerfile 中先 `COPY requirements.txt` 再 `COPY app.py` 的原因：
- Docker 按层构建，每层有缓存
- 依赖不变时，`pip install` 那层直接用缓存，不用重新安装
- 如果先复制所有代码，改一行代码就要重新装所有依赖
