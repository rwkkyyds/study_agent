# Section 1: FastAPI 入门 — 学习笔记

## 1. FastAPI 核心概念

FastAPI 是一个现代 Python Web 框架，三大卖点：
- **快**：性能接近 Node.js/Go（基于 Starlette + Pydantic）
- **自动文档**：代码即文档，自动生成 Swagger UI 和 ReDoc
- **类型安全**：利用 Python 类型提示（type hints）做数据校验

```
客户端请求 -> uvicorn(ASGI服务器) -> FastAPI(路由分发) -> 执行函数 -> 返回JSON
```

## 2. 路由（Route）

路由 = URL 路径 + HTTP 方法 -> 处理函数

```python
@app.get("/")           # GET 请求
@app.post("/items")     # POST 请求
@app.put("/items/{id}") # PUT 请求
@app.delete("/items/{id}") # DELETE 请求
```

HTTP 方法语义：
| 方法 | 用途 | 幂等性 |
|------|------|--------|
| GET | 查询资源 | 是 |
| POST | 创建资源 | 否 |
| PUT | 全量更新 | 是 |
| DELETE | 删除资源 | 是 |

## 3. 参数类型

FastAPI 自动根据参数位置判断类型：

| 参数类型 | 声明方式 | 示例 |
|----------|----------|------|
| 路径参数 | 函数参数名与 URL 中 `{xxx}` 对应 | `@app.get("/items/{item_id}")` `def f(item_id: int)` |
| 查询参数 | 函数参数名不在路径中 | `def f(keyword: str, limit: int = 10)` |
| 请求体 | Pydantic BaseModel | `def f(item: ItemCreate)` |
| 路径元数据 | `Path(...)` | `item_id: int = Path(..., description="ID")` |
| 查询元数据 | `Query(...)` | `limit: int = Query(10, ge=1, le=100)` |

## 4. Pydantic 数据校验

Pydantic 是 FastAPI 的数据校验引擎，核心用法：

```python
from pydantic import BaseModel, Field
from typing import Optional

class ItemCreate(BaseModel):
    name: str = Field(..., min_length=1, max_length=50)  # 必填，长度限制
    price: float = Field(..., gt=0)                        # 必填，大于0
    description: Optional[str] = Field(None, max_length=500)  # 可选
    in_stock: bool = Field(True)                            # 默认值 True
```

Field 常用约束：
- `...` → 必填
- `Optional` → 可选（默认 None）
- `gt` / `ge` → 大于 / 大于等于
- `lt` / `le` → 小于 / 小于等于
- `min_length` / `max_length` → 字符串长度

**核心价值**：请求数据不符合规则时，FastAPI 自动返回 422 错误 + 详细错误信息，不用手写 if-else 判断。

## 5. 异步 I/O（async/await）

```python
# 同步：阻塞，一个请求卡住，其他请求排队
@app.get("/sync")
def sync_endpoint():
    time.sleep(2)        # 阻塞整个事件循环
    return {"ok": True}

# 异步：非阻塞，等待时 CPU 处理其他请求
@app.get("/async")
async def async_endpoint():
    await asyncio.sleep(2)  # 不阻塞，让出 CPU
    return {"ok": True}
```

什么时候用 async：
- 涉及 IO 操作（网络请求、数据库查询、文件读写）→ 用 `async def` + `await`
- 纯计算密集 → 用普通 `def` 即可

## 6. HTTPException 异常处理

```python
from fastapi import HTTPException

if item_id not in db:
    raise HTTPException(status_code=404, detail="商品不存在")
```

FastAPI 会自动将异常转为标准 JSON 错误响应，不用手动构造。

## 7. 实际项目中的代码规范（本节已实践）

- Pydantic 模型做输入校验（请求体）+ 输出约束（response_model）
- try-except / HTTPException 做异常处理
- logging 做日志记录（后续小节强化）
- 类型提示贯穿所有函数签名
