# Section 4: Embedding 原理与本地向量库 — 学习笔记

## 1. Embedding 核心概念

Embedding = 把文本变成一组数字（向量），让计算机能"理解"语义。

```
"猫坐在垫子上" -> [0.2, 0.8, -0.1, 0.5, ...]  (高维向量)
"小猫趴在垫子" -> [0.21, 0.79, -0.12, 0.48, ...]  (相似向量)
"今天天气真好" -> [-0.5, 0.1, 0.9, -0.3, ...]  (不同向量)
```

关键特性：语义相似 -> 向量距离近，语义不同 -> 向量距离远。

## 2. 余弦相似度

衡量两个向量的相似程度：

```
cos(θ) = A·B / (|A| × |B|)
```

| 值 | 含义 |
|----|------|
| 1 | 完全相同方向（语义一致） |
| 0 | 正交（无关） |
| -1 | 完全相反（语义对立） |

```python
import numpy as np

def cosine_similarity(a, b):
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))
```

## 4. 向量数据库核心操作

```python
# 创建集合
collection = client.create_collection("name", embedding_function=ef)

# 插入
collection.add(documents=["文本"], metadatas=[{}], ids=["id1"])

# 检索（自动向量化 query）
results = collection.query(query_texts=["问题"], n_results=2)

# 过滤检索
results = collection.query(query_texts=["问题"], where={"topic": "RAG"})

# 删除
collection.delete(ids=["id1"])
```

## 5. RAG 检索链路

```
原始文档 -> 分块 -> Embedding -> 向量数据库
                                    │
用户问题 -> Embedding -> 向量相似度检索 -> Top-K 文档 -> LLM 生成回答
```

本节覆盖：分块 + Embedding + 向量库存储 + 检索。
